Privacy Policy

Last updated: 2026-11-13

Who uses this tool

yt-playlist is a personal tool used only by its owner. It is not offered to anyone else.

What data it accesses

When the owner signs in with Google, the tool uses the YouTube Data API v3 to access the owner's own YouTube account data that is needed for its functions: the owner's playlists and playlist items, videos the owner uploaded, and basic channel information.

How the data is used

The data is used only to carry out the playlist operations the owner asks for (reading, reordering and replacing playlist items, and changing the privacy setting of the owner's own videos).

Storage and sharing

The sign-in token is stored only on the owner's own computer. The data is not sent to any third party, not sold, and not used for advertising.

YouTube API Services

This tool uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Revoking access

Access can be revoked at any time from the Google Account security settings: https://myaccount.google.com/permissions.

Contact

Questions can be sent through the issue page of this repository.
